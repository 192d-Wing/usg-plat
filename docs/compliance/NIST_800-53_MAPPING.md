# NIST SP 800-53 Rev 5 Control Mapping

Version 0.1.0, SIEM log schema 4 (`plat_audit::LOG_SCHEMA_VERSION`).

Status values:

- **Implemented**: code plus automated test evidence. Tests ran on the macOS
  development host (`make test`: 173 passed, 0 failed, 0 ignored, after fix
  round 3).
- **Implemented (not tested on Linux)**: the mechanism is in `deploy/` or in
  Linux-only code (`#[cfg(target_os = "linux")]`, the TUN backend). There is
  no automated test, and the Linux checklist in
  [`LINUX_VERIFICATION.md`](LINUX_VERIFICATION.md) has not been run. Do not
  present this as tested ATO evidence until that checklist passes.
- **Partial**: some of the control is implemented and tested; the gap is
  named with its POA&M ID.
- **Planned**: not implemented; tracked in [`POAM.md`](POAM.md).
- **Inherited**: provided by the platform or the site.

Paths are relative to `crates/` unless they start with `services/`,
`deploy/` or `config/`. Test names are `file::test` in the crate named.
