# Plan of Action and Milestones

Every `// POAM:` marker in the code has an entry here with the same ID
(`make compliance-annotations` lists the markers). Entries marked "no code
marker" describe a gap that has no single code site yet, or whose marker has
not been added; the owner of the fix adds `// POAM: POAM-0xx` when the work
starts. Owner and milestone are placeholders until assigned.
